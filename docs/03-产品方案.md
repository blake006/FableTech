## 1. 产品定位

**FableTech Browser** —— 面向中国出海团队的**免费自托管指纹浏览器**。

一句话：*"把 Multilogin / AdsPower 的档案管理体验，装进一个完全免费、数据不出本机、引擎可插拔的便携应用里。"*

| | 商业指纹浏览器 | **FableTech** |
|---|---|---|
| 费用 | $99~$399/月 起，按档案数+坐席收费 | **免费**（引擎用开源的 Camoufox） |
| 数据 | 档案/Cookie 上云同步 | **纯本地 + AES-256 加密** |
| 引擎 | 闭源内核模拟 | Camoufox 主引擎（可换 CloakBrowser） |
| 场景配方 | 通用 RPA，少有针对 Outlook/国内出海团队 | **内置 Outlook 注册、社媒发帖、养号配方** |
| 部署 | 装客户端 + 云端账号 | **win-x64-portable 单包，解压即用** |

## 2. 团队场景与需求提炼

### 2.1 场景 A：Outlook 邮箱账号注册

**流程还原**（signup.live.com）：
1. 打开注册页 → 2. 填姓名/生日 → 3. 选邮箱名/密码 → 4. **人机验证（FunCaptcha）** → 5. **手机短信验证** → 6. 注册完成 → 7. 保持登录态（养号）

**风控点**：Microsoft 对 IP 信誉、指纹一致性、行为节奏综合评分；机房 IP + 默认指纹 = 秒拒。

**FableTech 需求**：
- 档案 = 全新指纹（Camoufox + BrowserForge 种子），UA/时区/语言与住宅代理出口地理一致
- 表单自动填写（账号规格表驱动：姓名库、生日分布、用户名规则、强密码生成并加密保存）
- **CAPTCHA / 短信验证 = 人工介入点**：自动化暂停并弹窗提醒，人工完成后一键继续
- 注册成功自动存档 Cookie（加密）、记录账号元数据、生成「7 天养号计划」

### 2.2 场景 B：海外社媒注册 / 推广 / 维护

**平台**：X (Twitter)、TikTok、Instagram、Facebook、YouTube（v1 优先 X + TikTok，其余走通用配方框架）。

| 阶段 | 风控重点 | FableTech 能力 |
|---|---|---|
| 注册 | 指纹 + IP + 验证方式 | 同场景 A；手机验证走人工/短信平台适配器 |
| 推广（发帖/互动） | 行为拟人度、频率、内容重复度 | 拟人输入（随机节奏）、任务调度（错峰、限量）、内容队列去重 |
| 维护（养号/登录巡检） | 登录态失效、账号异常/封禁 | 定时登录巡检（Cookie 有效性）、异常标记、自动重验流程引导 |

### 2.3 场景 C：团队协作

- 档案批量导入/导出（加密档案包，团队成员间分享）
- 代理池共享与分组（按平台/地区标签）
- 操作日志与截图审计（谁在什么时候启动了哪个档案）
- 主密码 + 本地加密，满足团队内账号资产安全交接

## 3. 功能清单（P0 = v1.0 必须，P1 = v1.1，P2 = v2.0）

### P0（v1.0 — 本次交付）

**档案管理**
- [x] 档案 CRUD：名称、平台标签、备注、分组、状态（活跃/异常/封禁）
- [x] 档案指纹：BrowserForge 生成，**种子持久化**（同档案每次启动指纹一致）
- [x] 档案引擎选择：Camoufox（默认）/ CloakBrowser（有 key 时）/ Patchright-Chromium
- [x] 一键启动（headed 原生窗口）+ 进程管理（关闭/强制关闭/查看运行中）

**代理管理**
- [x] 代理 CRUD：类型（HTTP/HTTPS/SOCKS5）、地址、端口、用户名、密码（加密）
- [x] 批量导入（文本粘贴：`协议://user:pass@host:port` 每行一条）
- [x] 连通性测试（SOCKS 握手 + 目标站点可达性）
- [x] 出口地理查询（ip-api.com）→ 自动匹配档案时区/locale
- [x] 档案绑定代理；UI 中凭证脱敏显示

**Cookie 与账号数据**
- [x] Cookie 导入（Netscape 格式 / JSON）/ 导出
- [x] Cookie 本地 AES-256-GCM 加密存储
- [x] 账号元数据（平台、用户名、密码、2FA 备注、注册邮箱、状态）加密存储

**自动化（Recipe 框架）**
- [x] Recipe 步骤机：步骤定义 + 人工介入点（暂停等待人工，恢复继续）
- [x] 内置 Recipe：**Outlook 注册**（半自动，含 CAPTCHA/短信人工节点）
- [x] 内置 Recipe：**X 发帖**（登录态校验 → 拟人输入 → 发布 → 结果记录）
- [x] 内置 Recipe：**TikTok 发视频**（上传流程占位实现，选择器可配置）
- [x] 账号健康巡检：定时任务，验证登录态，标记失效

**任务调度**
- [x] 任务队列：立即执行 / 定时执行 / 间隔执行
- [x] 并发上限控制、失败重试、执行日志 + 失败截图

**安全**
- [x] 首次启动设置主密码（scrypt 派生 AES 密钥，内存中不留明文密钥文件）
- [x] 数据库与 Cookie 文件加密；无遥测、无任何外发（除用户显式操作的 ip-api 查询）

**GUI 与 CLI**
- [x] CustomTkinter 中文 GUI：档案 / 代理 / 任务 / 日志 / 设置 五个页面
- [x] CLI（供脚本化）：`create-profile / launch / run-recipe / export-cookies` 等

**打包**
- [x] `win-x64-portable`：PyInstaller 单目录 + 便携启动器 + README

### P1（v1.1）
- 档案包加密导出/导入（团队分享）
- 短信验证码平台适配器（sms-activate 等 API 桥接，可选）
- 更多社媒配方：Instagram、Facebook、YouTube

## 4. 合规与风控（团队 SOP 建议）

1. **合法用途**：仅用于管理团队自有账号的营销运营；不用于欺诈、垃圾信息、黄赌毒、规避金融/政府风控。
2. **平台 ToS**：各社媒对多账号有明确限制，建议控制同 IP 段账号密度、养号节奏，降低封号面。
3. **代理合规**：使用正规代理商住宅/移动 IP；不从事攻击、爬取受保护数据。
4. **数据安全**：主密码丢失 = 数据不可恢复（设计如此）；团队内主密码需有保管制度。
5. **引擎许可**：CloakBrowser 仅在团队自用场景按订阅使用；不二次分发、不预装进对外分发的包。

> 以上写入 README 与 GUI「关于」页，团队每位使用者首次启动需阅读确认。

## 5. 技术路线（摘要，详见 `docs/04-架构设计.md`）

```
FableTech = 自研产品外壳（MIT） + 可插拔引擎层
├─ 引擎层：Camoufox（主，免费）｜CloakBrowser（可选增强）｜Patchright-Chromium（备选）
├─ 指纹层：BrowserForge（种子持久化，档案级指纹）
├─ 产品层：档案管理 / 代理池 / Cookie 加密仓 / Recipe 自动化 / 调度器 / 日志审计
├─ 安全层：主密码 → scrypt → AES-256-GCM（SQLite + Cookie + 凭证）
└─ 交付层：Python 3.11+ / CustomTkinter GUI / PyInstaller → win-x64-portable.zip
```
