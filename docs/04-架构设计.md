## 1. 总体架构

```
┌─────────────────────────────────────────────────────────────────┐
│                        FableTech Browser                         │
│                     （Python 3.11+ / win-x64）                    │
├─────────────────────────────────────────────────────────────────┤
│  展示层  CustomTkinter GUI  ◄──────────►  CLI (argparse)          │
│         档案页 │ 代理页 │ 任务页 │ 日志页 │ 设置页                   │
├─────────────────────────────────────────────────────────────────┤
│  服务层  ProfileService  ProxyService  CookieVault  TaskScheduler │
│         AutomationEngine(Recipe 步骤机)  SelfCheck               │
├─────────────────────────────────────────────────────────────────┤
│  指纹层  FingerprintService（BrowserForge，种子持久化）             │
├─────────────────────────────────────────────────────────────────┤
│  引擎层  BrowserEngine（抽象）                                     │
│         ├─ CamoufoxEngine   （主引擎，MPL-2.0，Firefox 定制）       │
│         ├─ CloakEngine      （可选，license key，Chromium C++补丁） │
│         └─ ChromiumEngine   （备选，Patchright + 系统 Chrome）      │
├─────────────────────────────────────────────────────────────────┤
│  存储层  SQLite(fabletech.db) + 加密文件仓(cookies/*.enc)          │
│         主密码 → scrypt → AES-256-GCM 密钥（仅内存持有）            │
├─────────────────────────────────────────────────────────────────┤
│  运行时依赖（pip，首次按需安装） camoufox / browserforge /          │
│  patchright / playwright —— 浏览器二进制首次启动自动下载(~200MB)     │
└─────────────────────────────────────────────────────────────────┘
```

**关键设计决策**：
1. **引擎可插拔**：所有引擎实现同一抽象接口 `BrowserEngine`，档案记录 `engine` 字段；新引擎（如未来 Chromium 分叉）只需新增一个实现类。
2. **种子持久化**：档案创建时生成随机 `seed`；指纹由 `seed` 确定性派生（BrowserForge 的 `generate(seed=...)`），保证同一档案跨会话指纹恒定。
3. **自动化即 Playwright**：三个引擎都暴露标准 Playwright `Page` 对象，Recipe 代码引擎无关。
4. **半自动步骤机**：Recipe 由「步骤」组成，步骤可声明 `requires_human=True`（暂停并通知人工），恢复后继续 —— 这是 Outlook 注册类流程的唯一正确形态。
5. **纯本地、零遥测**：除用户显式触发的 ip-api 查询外，无任何网络外发。

## 3. 核心模块契约

### 3.1 crypto.py —— Vault

```python
class Vault:
    def __init__(self, db_path: Path): ...          # 库存在则提示输入主密码
    @staticmethod
    def is_initialized(db_path: Path) -> bool: ...
    @classmethod
    def initialize(cls, db_path: Path, master_password: str) -> "Vault": ...
    def encrypt(self, plaintext: str | bytes) -> bytes: ...   # AES-256-GCM, 随机 12B nonce
    def decrypt(self, blob: bytes) -> bytes: ...
```
- 密钥派生：`scrypt(password, salt=32B, n=2**15, r=8, p=1)` → 32B 密钥；校验值（加密固定串）存库用于验证密码正确性。
- 加密格式：`magic(4B="FTV1") | nonce(12B) | ciphertext+tag`。

### 3.2 storage.py —— SQLite

单文件 `fabletech.db`，表：

```sql
profiles(id TEXT PK, name, engine TEXT, seed TEXT, platform_tags TEXT,
         group_name, proxy_id TEXT NULL, status TEXT, notes TEXT,
         account_meta_enc BLOB, created_at, updated_at, last_launched_at)
proxies(id TEXT PK, type TEXT, host, port, username_enc BLOB, password_enc BLOB,
        tags TEXT, last_check_at, latency_ms, country, city, enabled INT)
cookies(profile_id TEXT PK, engine TEXT, blob BLOB, updated_at)   -- blob 为加密 JSON
tasks(id TEXT PK, recipe TEXT, profile_id TEXT, params TEXT(JSON),
      schedule TEXT, status TEXT, attempts INT, last_error, created_at, updated_at)
logs(id INTEGER PK AUTOINC, ts, level, source, profile_id NULL, message, screenshot_path NULL)
settings(key TEXT PK, value TEXT)
```

所有写操作参数化；`id` 用 `uuid4().hex[:12]`。

### 3.3 fingerprint.py —— 指纹服务

```python
def generate_fingerprint(seed: str | None = None) -> dict:
    """BrowserForge 生成，seed 缺省随机。返回统一指纹配置：
    {os, browser, screen, viewport, locale, timezone, fonts, hardwareConcurrency,
     deviceMemory, webgl, userAgent, seed}"""
def engine_config(fp: dict, engine: str) -> dict:
    """把统一指纹翻译成各引擎启动参数（camoufox: os/locale/timezone/screen/...;
       cloak: fingerprint seed 透传; patchright: 需外挂 UA/viewport 配置）"""
```
- 依赖 browserforge；**运行时缺依赖时给出明确中文提示**（「请在设置页安装运行时组件」），不崩溃。

### 3.4 engines/base.py —— 引擎抽象

```python
@dataclass
class LaunchSpec:
    profile_id: str; user_data_dir: Path; proxy: str | None  # scheme://user:pass@host:port
    fingerprint: dict; headless: bool; extra: dict

class BrowserEngine(ABC):
    name: str                       # "camoufox" | "cloak" | "chromium"
    def available(self) -> tuple[bool, str]: ...            # (是否可用, 中文提示)
    def ensure_runtime(self) -> bool: ...                    # pip 安装 + 浏览器下载
    def launch(self, spec: LaunchSpec) -> EngineSession: ...
    def close(self, session): ...

class EngineSession:
    page           # Playwright Page（camoufox/cloak/patchright 皆为标准 Playwright 对象）
    context        # BrowserContext（持久化）
    cdp_endpoint   # str | None（cloak 暴露 CDP；camoufox 为 None）
    def save_state(self, path: Path): ...  # context.storage_state → 由 CookieVault 加密
    def load_state(self, path: Path): ...  # 注入 Cookie
```

**各引擎要点**：
- `CamoufoxEngine`：`from camoufox import AsyncCamoufox`（或同步封装）；`launch(headless=False, proxy={server,username,password}, os=..., locale=..., timezone_id=..., screen=..., geoip=True 时按代理自动)`；persistent context 目录 = 档案 user_data_dir。**这是主路径，必须最先实现并通过冒烟测试**。
- `CloakEngine`：`import cloakbrowser`（不存在则不可用）；license key 从设置页读取（环境变量 `CLOAKBROWSER_LICENSE_KEY`）；同样 proxy + fingerprint 配置。
- `ChromiumEngine`：`import patchright`（不存在则不可用）；`channel="chrome"` 若系统已装 Chrome，否则用 patchright 自带 Chromium；`launch_persistent_context(user_data_dir=..., headless=False, no_viewport=True)`；指纹仅透传 UA/viewport（能力受限，UI 明确标注「该引擎不伪造指纹，仅用于 Chromium-only 站点」）。

### 3.5 automations/base.py —— Recipe 步骤机

```python
@dataclass
class Step:
    name: str
    run: Callable[[RecipeContext], Awaitable/Any] | None
    requires_human: bool = False     # True 时执行到该步暂停，通知人工
    human_prompt: str = ""           # 人工操作指引（GUI 弹窗展示）

class Recipe(ABC):
    name: str
    title: str
    def steps(self, ctx) -> list[Step]: ...
    def run(self, session, ctx) -> RecipeResult:
        for step in self.steps(ctx):
            log(step.name)
            if step.requires_human:
                notify_human(step.human_prompt)   # GUI 弹窗/声音；CLI 下等待回车
                wait_for_resume()
            step.run(ctx)
        return RecipeResult(success=..., data=...)
```

**内置 Recipe（v1）**：
1. `outlook_register`：半自动。步骤：打开 signup.live.com → 填姓名/生日 → 填用户名/密码（由 `ctx.params`：姓名库条目、用户名规则、密码）→ **人工：FunCaptcha** → **人工：短信验证码** → 完成校验（URL 跳转检测）→ `save_state` 加密存档 → 写 account_meta。
2. `x_post`：加载档案 → 校验登录（x.com 首页头像元素）→ 打开发帖框 → 拟人输入 `ctx.params["text"]` → 发布 → 校验结果 → 记录。
3. `tiktok_post`：上传流程，选择器集中放 `SELECTORS` 常量（站点改版只改这里）。
4. `health_check`：加载档案 → 打开平台首页 → 判定登录态/风控提示（选择器配置化）→ 更新档案状态。

### 3.6 scheduler.py —— 调度器

- 单例，GUI/CLI 共用；线程池执行 Recipe（默认并发 2，可配）。
- 任务状态机：`pending → running → done / failed / waiting_human`。
- `waiting_human` 任务在 GUI 任务页高亮，人工介入后「继续」。
- 失败重试：指数退避，最多 3 次；每次失败自动截图存 `data/screenshots/`。

### 3.7 config.py —— 路径策略

- **便携模式**（默认，`FableTech.exe` 同级存在 `portable.flag` 或 exe 所在目录可写）：全部数据落 `./data/`（db、cookies、screenshots、logs）。
- **安装模式**：`%LOCALAPPDATA%/FableTech/`。
- 判断逻辑封装在 `config.paths()`，GUI 设置页显示当前数据目录。

## 4. 关键流程

### 4.1 启动档案

```
GUI 点击「启动」→ ProfileService.launch(profile_id)
  → 读档案（engine/seed/proxy_id）
  → FingerprintService.engine_config(fp, engine)
  → ProxyService.resolve(proxy_id) → 加密口令解密 → proxy URL
  → CookieVault.load(profile_id) → 解密 JSON（存在则注入）
  → Engine.launch(LaunchSpec) → headed 窗口
  → 记录 last_launched_at + 日志
```

### 4.2 运行 Outlook 注册 Recipe

```
任务页新建任务（recipe=outlook_register, profile=X, params={姓名库, 用户名规则}）
  → Scheduler 取任务 → 引擎启动档案（headless=False）
  → 步骤机执行到 FunCaptcha 步 → requires_human → 状态 waiting_human
  → GUI 弹窗「请完成人机验证后点击继续」+ 声音提示
  → 人工完成 → 点击继续 → 短信验证码同理 → 完成
  → save_state 加密 → account_meta 写入（平台=outlook, 用户名, 密码 enc）
  → 任务 done，日志+截图归档
```

### 4.3 打包（win-x64-portable）

```
scripts/build_portable.py
  1) venv + pip install -r requirements.txt requirements-runtime.txt
  2) pyinstaller --windowed --onedir --name FableTech \
       --add-data "fabletech/ui/assets;fabletech/ui/assets" \
       --hidden-import camoufox --hidden-import browserforge --hidden-import playwright \
       --hidden-import patchright ...
  3) 组装 portable 目录：
       FableTech-portable/
         FableTech.exe（GUI）/ fabletech-cli.exe（CLI）
         _internal/（依赖）
         data/（空，首次运行生成）
         engines-runtime/（requirements-runtime.txt 副本 + 安装说明）
         README-portable.txt
  4) zip → dist/FableTech-1.0.0-win-x64-portable.zip
```

> 浏览器二进制（Firefox/Chromium，~200MB）**不预装**：首次启动对应引擎时由 camoufox/cloakbrowser 自动下载（有明确中文进度提示）。这保证便携包 < 60MB 且规避 CloakBrowser 二进制再分发限制。

## 5. 安全设计

| 威胁 | 对策 |
|---|---|
| 库文件被拷走直接读 | SQLite 内敏感字段（账号元数据）+ Cookie 仓全部 AES-256-GCM；密钥仅内存 |
| 主密码弱 | 最少 8 位，建议 12+；scrypt(n=2^15) 抗暴力 |
| 日志泄漏凭证 | logger 脱敏（proxy URL 中 user:pass 掩码、密码字段不记录） |
| 误外传 | 无遥测代码；网络仅：ip-api 查询（显式）、引擎下载（显式）、Recipe 访问目标站点 |
| 恶意 Recipe | v1 仅内置 Recipe；v2 引入第三方 Recipe 时加签名校验 |
| 便携包 UAC/权限 | 纯用户态运行，不写注册表、不装服务 |

## 6. 非目标（v1 明确不做）

- 不做浏览器内核分叉/编译（开源引擎已覆盖）
- 不做云同步/多用户服务端（纯本地，团队用加密档案包分享）
- 不做移动端模拟（v2 视需求）
- 不做 CAPTCHA 自动识别（人工介入点是设计而非缺陷）
- 不做内置代理售卖/中转
