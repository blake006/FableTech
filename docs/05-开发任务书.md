## 2. 实现顺序（严格按序，每步完成即自测）

### Phase A：基础设施（无外部依赖，必须 100% 单测通过）
1. `config.py` + `logger.py` + `crypto.py`（Vault）→ 写 `tests/test_crypto.py`：初始化/加解密往返/错误密码拒绝/篡改检测（GCM tag）。
2. `storage.py`（SQLite，全部参数化）→ `tests/test_storage.py`：profiles/proxies/cookies/tasks/logs 五表 CRUD + 级联清理。
3. `fingerprint.py`（browserforge 封装，seed 持久化）→ `tests/test_fingerprint.py`：同 seed 两次生成结果一致；不同 seed 不同；engine_config 三个引擎键齐全。
4. `proxy.py`（解析/批量导入/掩码/连通测试**可 mock**）→ `tests/test_proxy_parse.py`：各种 URL 形态、批量文本、异常行跳过。
5. `cookies.py`（Netscape 解析 + JSON 互转 + 经 Vault 加密封存）→ `tests/test_cookies_roundtrip.py`：roundtrip 保真 + 加密落盘读回。

### Phase B：引擎层
6. `engines/base.py`（ABC + LaunchSpec + EngineSession，含 `save_state/load_state`）。
7. `engines/camoufox_engine.py`：**最重要**。persistent context = 档案 user_data_dir；proxy 传 dict；指纹按 `engine_config(fp,'camoufox')` 映射 camoufox 启动参数（os/screen/locale/timezone_id/humanize 等，以 camoufox 当前版本文档为准：`python -c "import camoufox, inspect; print(inspect.signature(camoufox.AsyncCamoufox.launch))"` 自行核实签名，不要凭记忆写参数）。`ensure_runtime()` 调 `camoufox fetch` 下载浏览器。
8. `engines/cloak_engine.py`（import guard；license key 从 settings/环境变量读取）。
9. `engines/chromium_engine.py`（patchright import guard；系统 Chrome 优先；UA/viewport 透传；UI 标注能力受限）。

### Phase C：服务层
10. `profiles.py`（CRUD + launch 编排 + 进程注册表：运行中档案不可重复启动）。
11. `automations/base.py`（Recipe 步骤机 + requires_human + notify/resume 回调注入，GUI/CLI 两种宿主）。
12. 四个 Recipe：`outlook_register`（半自动，人工介入点 2 处）、`x_post`、`tiktok_post`（选择器集中常量）、`health_check`。
13. `scheduler.py`（队列/并发/重试/截图/waiting_human 状态机）。
14. `selfcheck.py`（预留接口，v1 返回 not-implemented 友好提示即可）。

### Phase D：GUI + CLI
15. `ui/` 五页面（档案/代理/任务/日志/设置）+ 主窗口；首次启动主密码创建/解锁流程；引擎可用性检测与「一键安装运行时」按钮（pip 调用 venv 内 python —— 打包后用 `sys.executable`）。
16. `cli.py`：`create-profile / launch / run-recipe / export-cookies / import-cookies / proxy-test` 子命令，`--help` 齐全，供脚本化与冒烟测试。

### Phase E：测试与打包
17. `pytest tests/ -q` 全绿；补 `tests/test_recipes_smoke.py`（不启动真实浏览器：mock EngineSession 验证步骤机状态流转：running → waiting_human → resume → done）。
18. `scripts/build_portable.py` 实现并**实际执行**，产出 `dist/FableTech-1.0.0-win-x64-portable.zip`。
19. `README.md`（中文：功能、快速开始、Recipe 用法、FAQ、合规声明）、`LICENSE`（MIT）、`.gitignore`、`requirements.txt`、`requirements-runtime.txt`。

## 3. 关键实现要求（红线）

1. ** camouflagefox 启动参数必须核实**：用 `inspect.signature` 或 `python -m camoufox --help` 查证当前版本真实签名，禁止凭训练记忆写参数（ camoufox API 历次有变动）。
2. **SQLite 全部参数化**，禁止字符串拼接 SQL；`id` 统一 `uuid4().hex[:12]`。
3. **凭证脱敏**：日志/UI 中代理 URL 必须掩码（`socks5://u***:p***@host:port`）；密码永不进日志。
4. **路径安全**：导入/导出文件路径做规范化与扩展名校验，防路径穿越。
5. **异常兜底**：引擎不可用/下载失败时给中文可操作提示，**应用不崩溃**；GUI 线程内不阻塞（引擎启动放子线程 + 状态回调）。
6. **便携优先**：`config.py` 判断 `portable.flag` 存在或 exe 同级可写 → 数据落 `./data/`；默认关闭任何自动更新检查。
7. **不引入**：任何云 SDK、遥测、自动上传、`eval/exec` 用户输入、全局 `except: pass` 吞异常。
8. **编码**：所有源码 UTF-8；Windows 上文件读写显式 `encoding="utf-8"`。
