# FableTech · 开源指纹浏览器调研报告

> 调研人：Step-5-Preview（主 Agent）
> 调研日期：2026-10-16
> 调研方式：GitHub API + 官方文档站 + 社区评测（CSDN / 知乎）交叉验证
> 仓库：https://github.com/blake006/FableTech

---

## 1. 调研背景与目标

FableTech 团队需要一套自主可控的**指纹浏览器（反检测浏览器）**，用于：

1. 海外社媒账号（X / TikTok / Instagram / Facebook / YouTube 等）的**注册、推广、日常维护**
2. Outlook 等海外邮箱账号的**注册与养号**

本次调研的目标：

- 找出 GitHub 上主流的开源指纹浏览器 / 反检测浏览器仓库
- 全面对比各仓库的特性与优缺点
- 判断哪些能力适合组装进 FableTech 自有产品
- 为后续产品方案与架构设计提供依据

---

## 2. 调研范围与方法

- **直接来源**：GitHub REST API（仓库元数据：star / 许可证 / 语言 / 最近推送时间）、官方文档站（camoufox.com、cloakbrowser.dev）、PyPI
- **交叉验证**：中文社区深度评测（CSDN 博客、知乎）对技术实现的解读
- **筛选标准**：与「浏览器指纹伪装 / 反自动化检测」直接相关、开源、近 2 年有维护或仍是事实标准

> ⚠️ 注：star 数、推送时间均为 2026-10-16 当日通过 GitHub API 实测值。

---

## 3. 核心结论（TL;DR）

1. **开源生态里没有"开箱即用的完整指纹浏览器产品"**。主流开源项目全部是「引擎 / 库 / 框架」层，缺的是**多档案管理 GUI + 代理管理 + Cookie 管理 + 自动化调度**这一层产品化封装 —— 这正是商业产品（Multilogin / AdsPower / GoLogin 等）的核心价值所在，也是 FableTech 的机会。
2. **引擎层双雄格局**：
   - **Camoufox**（Firefox 定制构建，MPL-2.0）：**完全免费开源**，C++ 源码级指纹注入，适合作为 FableTech 的**主引擎**。
   - **CloakBrowser**（Chromium C++ 补丁，MIT）：**实测检测通过率最高**（30+ 检测系统全过），但**引擎二进制按并发数收费**、禁止再分发，适合作为**可选增强引擎**（自用合规）。
3. **指纹生成**用 **BrowserForge**（Apache-2.0，与 Camoufox 同作者，统计分布真实）。
4. **Chromium 自动化**用 **Patchright**（Apache-2.0，补丁版 Playwright，仅修 CDP 泄漏、不改指纹）。
5. **已停更/弱化的项目**（undetected-chromedriver、puppeteer-extra、rebrowser-patches）不建议在新产品中使用。
6. **FableTech 技术路线**：不做 Chromium 内核分叉（不可行也不必要），而是**自研产品外壳（档案/代理/Cookie/自动化/GUI）+ 可插拔引擎层（Camoufox 主 + CloakBrowser 可选 + Patchright 备选）**，打包为 win-x64-portable。

## 5. 逐一深入分析

### 5.1 CloakBrowser（CloakHQ）—— 检测通过率之王

**是什么**：一个真正的 Chromium 二进制，指纹在 **C++ 源码层面**被修改后重新编译（不是 JS 注入、不是启动参数伪装）。官方口径「73 个 C++ 补丁」编译进 Chromium v154。对 Playwright / Puppeteer / Selenium 是 drop-in 替换（Python / JS / .NET 三端）。

**核心特性**：
- **73 项源码级指纹补丁**：Canvas、WebGL、WebGPU、Audio、字体枚举与度量、GPU vendor/renderer、hardwareConcurrency、deviceMemory、screen、system colors、媒体查询、时区、locale/language、UA + Client Hints、语音合成 voices、媒体设备、DRM 能力、WebRTC IP 屏蔽、storage quota、WebAuthn、Bluetooth、Web Share、驱动层输入行为、自动化信号清除
- **双层隐身**：浏览器层（C++ 补丁）+ 驱动层（去 CDP 泄漏、可选 humanize 拟人化：贝塞尔鼠标轨迹、自然键盘节奏、滚动物理）
- **humanize=True** 一个开关开启拟人化交互
- 平台：Windows x64 / Linux x64+ARM64 / macOS
- 首次启动自动下载二进制（~200MB，本地缓存）

**实测检测成绩**（官网，2026-10 对 Chromium v154 测试）：

| 检测系统 | 原生 Playwright | CloakBrowser |
|---|---|---|
| reCAPTCHA v3 | 0.1（bot） | 0.9（human） |
| Cloudflare Turnstile | FAIL | PASS |
| FingerprintJS | DETECTED | PASS |
| BrowserScan | DETECTED | 4/4 正常 |
| bot.incolumitas.com | 13 项失败 | 全部通过 |
| navigator.webdriver | true | false |
| CDP 检测 | Detected | Not detected |
| TLS 指纹 (ja3n/ja4) | 不匹配 | 与真实 Chrome 一致 |

**商业模式（重要）**：
- 免费 GitHub key = **同时只跑 1 个档案**；付费按并发数：Solo $19-29/月（5 并发）、Team $49-79（20）、Business $199（200）、Scale $499（2000）
- **二进制禁止再分发 / 改装**（OEM 需另购授权）；在自有基础设施内运行未修改的二进制是允许的
- 官方声明不解决 CAPTCHA，只减少无谓挑战；代理自备

**CloakBrowser Manager**（配套产品）：
- FastAPI + React 的 Web GUI，自托管，「Multilogin / GoLogin / AdsPower 的免费自托管替代」
- 每个档案独立指纹/GPU/代理/Cookie/历史，**每个运行中的档案暴露 CDP 端点**（Playwright/Puppeteer 可同时驱动，人看着窗口、脚本跑同一会话）
- 原生桌面窗口（Win/macOS）；Linux 走 Docker + VNC
- 单 token 认证、无遥测；仓库 license 标记为 NOASSERTION（官网宣称 MIT，两者不一致，采用前需核实）

**优点**：检测通过率实测最强；引擎+驱动双层隐身；Manager 证明了「档案管理 GUI + 引擎」的产品形态可行；原生窗口体验好。
**缺点**：引擎二进制按并发收费、禁止再分发（无法预装进我们的便携包）；许可证条款有摩擦；项目很新（2026-02 创建），生态与长期维护待观察。

### 5.2 Camoufox（daijro）—— 完全免费的开源反检测浏览器

**是什么**：基于 **Firefox** 的定制构建（分叉），在 **C++ 实现层**拦截并修改指纹数据（非 JS 注入）。当前版本 v146.0.1-beta.25（2026-01 起全部源码公开，MPL-2.0）。

**核心特性**：
- **指纹注入（不依赖 JS 注入）**：全部 navigator 属性（设备/OS/硬件/浏览器）、屏幕尺寸/分辨率/窗口/视口、地理位置、时区、locale、Intl、**WebRTC IP 协议级伪装**、语音 voices 等
- **图形指纹防护**：WebGL 参数/扩展/上下文属性/shader 精度格式、字体伪装与反指纹
- 与 **BrowserForge** 联动：按真实流量统计分布轮换设备特征，保证指纹**内部一致性**（Windows UA 不会配 Apple GPU）
- 拟人化鼠标移动、广告拦截、去臃肿（~200MB vs Chrome 800MB+）
- PyPI 包 `camoufox`，Playwright API 兼容，随 Firefox 版本持续更新
- headless-first，为 AI Agent 场景设计

**为什么选 Firefox 而非 Chromium**（官方理由）：Chrome 闭源难打补丁且 Chromium 版可被识别；CDP 是检测重灾区；Firefox 的 Juggler 协议层级更低、泄漏更少；Firefox 指纹抵抗研究更充分。

**优点**：**完全免费、源码公开、许可证友好（MPL-2.0，可商用可改装）**；指纹一致性强；轻量；社区活跃（1.2 万 star，日更）。
**缺点**：基于 Firefox，个别站点/应用对 Chromium 有硬性要求（少量）；面向自动化 API 设计，**没有自带的多档案管理 GUI**；有状态的能力（如某些企业站点兼容性）弱于 Chromium。

---

### 5.3 Patchright（Kaliiiiiiiiii-Vinyzu）—— 补丁版 Playwright

**是什么**：对 Playwright 打补丁的「undetected」版本，drop-in 替换（`from patchright.sync_api import ...`，其余代码不变）。**只补丁 Chromium 系浏览器，不支持 Firefox/WebKit**。

**核心补丁**：
- **Runtime.enable 泄漏**（最大补丁）：改用隔离执行上下文执行 JS，避免 CDP 层面泄漏
- Console API 整体关闭（避免 console 钩子检测）
- 命令行参数泄漏：加 `--disable-blink-features=AutomationControlled`、移除 `--enable-automation` 等
- 闭阴影根（Closed Shadow Root）可交互
- 官方声明通过：Cloudflare、DataDome、Akamai、Kasada、Shape/F5、Fingerprint.com、CreepJS 等

**重要认知边界**：Patchright **只修自动化痕迹（CDP 泄漏），不伪造浏览器指纹**（canvas/WebGL/字体等仍是本机真实值）。多账号场景下，多档案共用一个本机指纹会被关联 —— 所以它**不能单独当指纹浏览器用**，需要配合真实 Chrome + 指纹方案。

**最佳实践**（官方）：用真实 Google Chrome（`channel="chrome"`）、`launch_persistent_context`、`headless=False`、`no_viewport=True`、不覆盖 UA/headers。

**优点**：Apache-2.0、极其活跃（日更）、drop-in 成本低、Chromium 自动化隐身事实标准。
**缺点**：不解决指纹问题；仅 Chromium；依赖 Playwright 版本跟进。

---

### 5.4 nodriver（ultrafunkamsterdam）—— CDP 自动化

**是什么**：undetected-chromedriver 的继任者，纯 Python 的 CDP（Chrome DevTools Protocol）自动化框架，面向爬虫/机器人场景对抗 Cloudflare / hCaptcha 等。

**优点**：无 WebDriver 进程、API 简洁、AGPL-3.0、维护中。
**缺点**：**不做任何指纹伪装**（用本机真实 Chrome/Chromium），多账号场景价值有限；AGPL-3.0 有传染性，商用封装需注意。

**结论**：不作为 FableTech 引擎选型，仅作技术参考。

---

### 5.5 undetected-chromedriver（ultrafunkamsterdam）—— 遗产项目

12.9k star 的传奇项目（Selenium chromedriver 补丁），**2025-07 后基本停更**（issues 已关闭，1142 个 open issue）。GPL-3.0。对新项目已无采用价值，仅列此存档。

---

### 5.6 puppeteer-extra + stealth 插件（berstend）—— JS 隐身层

7.4k star 的 Puppeteer 插件框架，其 `stealth` 插件通过 JS 注入规避检测。**2024-07 后停更**，且 JS 注入路线本身已被现代检测（FingerprintPro / DataDome /  CreepJS）大量识破。**结论：不采用**，仅说明技术路线已被淘汰。

---

### 5.7 rebrowser-patches —— CDP 补丁集

Puppeteer/Playwright 的 CDP 补丁集合，思路与 Patchright 类似。**无许可证（商用法律风险）**，2025-05 后停更。**结论：不采用**。

---

### 5.8 BrowserForge（daijro）—— 指纹生成库

Camoufox 同作者的指纹/请求头生成库：按真实世界流量统计分布生成**内部一致**的指纹（屏幕、UA、navigator、WebGL、媒体设备等），支持 Python/Node。Apache-2.0。

**结论**：**直接采用**，作为 FableTech 的指纹生成核心（为 Camoufox 引擎生成指纹配置；亦可为 CloakBrowser 引擎生成档案种子）。

---

### 5.9 CloakBrowser Manager —— 产品形态参照

见 5.1。它的存在证明了两件事：

1. 「隐身引擎 + 自托管多档案管理 GUI」是市场刚需（对标 Multilogin/AdsPower 的免费方案能拿到 985 star）；
2. 我们的 FableTech 走的就是这条路，但要做到**引擎免费**（Camoufox 主引擎）、**功能更贴中国出海团队场景**（Outlook/社媒注册养号配方、代理池、中文 GUI、团队档案包分享）。

## 6. 商业指纹浏览器参照系（功能基准）

开源生态缺失的产品化能力，正好是商业产品的卖点，作为 FableTech 的功能基准（不抄代码，只对齐功能集）：

| 商业产品 | 核心功能基准 |
|---|---|
| Multilogin（老牌标杆） | 浏览器内核模拟（真实 Chrome/FF 组合）、每档案指纹+代理、Cookie 导入导出、团队协作、自动化 API |
| AdsPower | 中文团队常用，RPA 模板、窗口同步、代理检测、批量操作 |
| GoLogin | 云端同步、Cookie Robot、性价比 |
| Dolphin Anty | 批量注册场景优化、团队权限 |
| HubStudio / 比特浏览器 | 国内跨境电商团队常用、免费额度 |
| Kameleo / Incogniton / VMLogin / GenLogin / XLogin / MasLogin / RoxyBrowser 等 | 各有侧重（移动端模拟、云端、免费档） |

**共同的产品形态**：档案列表 → 启动独立窗口 → 档案级指纹+代理+Cookie → 自动化/手动操作 → 数据本地或云同步。FableTech v1 对齐该形态，差异化在**中文场景自动化配方**与**免费引擎**。

## 7. 开源生态结论与 FableTech 技术选型

| 层次 | 选型 | 理由 |
|---|---|---|
| **指纹引擎（主）** | Camoufox（MPL-2.0，免费） | 唯一完全免费且源码级指纹注入的成熟方案；Firefox 路线检测面小 |
| **指纹引擎（可选增强）** | CloakBrowser（license key，自用合规） | 检测通过率最强；对付硬目标站点（Cloudflare 重灾站点）时启用 |
| **Chromium 自动化层（备选）** | Patchright（Apache-2.0） | 少数必须 Chromium 的站点/应用；需配合系统 Chrome + 档案指纹配置 |
| **指纹生成** | BrowserForge（Apache-2.0） | 统计真实、内部一致 |
| **产品外壳** | FableTech 自研（Python + GUI） | 档案/代理/Cookie/自动化/调度/日志/加密，全部自研可控 |

**明确不采用**：undetected-chromedriver、puppeteer-extra stealth、rebrowser-patches（停更/无许可证/技术路线过时）、nodriver（无指纹能力）。

**许可证结论**：FableTech 自研部分采用 MIT；引用 Camoufox(MPL-2.0)/BrowserForge/Patchright(Apache-2.0) 均可商用；CloakBrowser 仅作运行时可选依赖且遵守其条款（不预装二进制、不再分发）。

## 8. 风险与注意事项

1. **平台合规**：指纹浏览器本身是合法隐私/安全工具，但用于注册账号需遵守各平台 ToS；建议团队建立合规 SOP（账号归属、养号节奏、内容规范）。本工具不提供、也不应用于欺诈、垃圾信息、规避金融/政府类风控。
2. **代理质量决定成败**：再强的浏览器也救不了被标记的机房 IP。社媒/Outlook 注册必须住宅/移动代理，且时区/语言与出口 IP 地理一致。
3. **检测对抗是动态军备竞赛**：引擎需保持更新（Camoufox 随 Firefox 更新）；FableTech 架构上必须保证**引擎可插拔、可热切换**。
4. **CloakBrowser 收费与再分发限制**：便携包内不预装其二进制，仅运行时按需下载（首次启动自动完成）。
